## 📝 Automation Blueprints
Click below to instantly import curated Elk-M1 security automations into your Home Assistant instance.

### Pre-Arm Status Validation
Checks for open zones before allowing the system to arm, routing a warning to your media players if a door or window is open.
[![Open your Home Assistant instance and show the blueprint import dialog.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https://github.com/trooperthorn/ha_int_elkm1/blob/main/blueprints/pre_arm_validation.yaml)

### Elk Voice Event Mirroring
Captures Elk-M1 physical voice announcements (ASCII `sw`/`dm` payloads) and rebroadcasts them across your smart speaker ecosystem.
[![Open your Home Assistant instance and show the blueprint import dialog.](https://my.home-assistant.io/badges/blueprint_import.svg)](https://my.home-assistant.io/redirect/blueprint_import/?blueprint_url=https://github.com/trooperthorn/ha_int_elkm1/blob/main/blueprints/voice_mirror.yaml)
